# Learning platform context

Use this workflow for educational content, learner progress, assessments, accessible navigation and course administration.

- Preserve the distinction between practice feedback, assessment scores and verified completion.
- Keep scoring and question selection reproducible where a feature requires it.
- Use semantic controls and keyboard navigation, and account for reduced motion and readable text.
- Preserve authorship and source attribution when transforming educational material.
- Use authorised test inputs. Do not include real learner records in repository fixtures or logs.
- Record evidence and unresolved limitations. Accessibility or correctness claims require appropriate verification.

The operator supplies the actual product requirements, application location, acceptance criteria and release destination.
